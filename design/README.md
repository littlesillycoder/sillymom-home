## 怎麼讀 `.dc.html`

每個檔案是一頁的設計原型：

- **`<helmet>` 裡的 `<style>`**：整頁共用的 CSS 規則。手機版的檔案有一大段共用規則（按鈕高度、輸入框、標籤、換行、連結靠右、圓角等），是設計定案的標準，實作時要做成共用元件或全站樣式，不要逐頁複製。
- **畫面本身**：一般 HTML，樣式寫在 `style` 屬性裡。顏色、字級、間距、圓角都以這裡為準。
- **`{{名稱}}`**：會變動的內容，值來自檔案最下面 `<script type="text/x-dc">` 裡 `renderVals()` 回傳的資料。這些資料是示意用的假資料，實作時改成從資料庫讀。
- **`<sc-for list="{{...}}">`**：重複的項目（列表）。
- **`<sc-if value="{{...}}">`**：依條件顯示的區塊。
- **`data-props`** 裡的 `enum`（例如 `status`、`step`、`kind`）：同一頁的不同狀態。例如「申請結果」有審核中、需要補件、已通過、未通過四種；截圖只截了預設那一種，其他狀態要看原始檔。
- **`[N]`、`[日期]`、`[NT$XXX]` 這類方括號**：要換成真實資料的位置。
- **`[律師審閱後放上]`**：條款正文，先保留這個位置。
- 連結 `href="Xxx.dc.html"` 代表頁面之間的跳轉，實作時換成對應的路由。

這些檔案需要設計工具的執行環境才能在瀏覽器打開，看畫面請直接看 `screenshots/`。

## 手機版和電腦版的差異

- 大部分頁面兩個版本都有。
- **只有電腦版**：管理後台 6 頁（`Admin*`）。後台只需要支援電腦寬度。
- **只有手機版**：
  - 選單（`Menu`、`MenuGuest`、`TechMenu`）：電腦版用頁首導覽列代替。
  - `MessagesChat`（訊息對話）：電腦版的訊息列表和對話在同一頁（`Messages`）。
  - `TechTermsOnline`（師傅條款已上線版）：電腦版照 `desktop/pages/TechTerms` 的版面，內容和手機版 `TechTermsOnline` 一樣（沒有步驟列和同意按鈕，顯示「你已同意這份條款」）。
  - `LineBind`（綁定 LINE）、`TermsSheet`（條款重點彈出）：電腦版沒有另外設計，用同樣的內容，做成置中的卡片或彈出視窗。
- 手機版和電腦版是**同一套程式**，用自動調整寬度做出兩種排版，不是兩套網站。
- 767 以下用手機版排版；768 以上用電腦版排版，並照「電腦版自動調整寬度規則」調整。
