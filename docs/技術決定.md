# 傻媽萬事通：技術決定

這份文件記錄已經定案的技術選擇和原因。實作時照這份走；要改任何一項，先更新這份文件，並寫明原因與日期。

最後更新：2026-11-03

## 1. 總覽

| 項目 | 決定 | 原因 |
|---|---|---|
| 網站框架 | Next.js（React + TypeScript） | 最普及、AI 工具和工程師都熟，之後賣給別的公司也好維護 |
| 資料庫、登入、檔案 | Supabase Pro（PostgreSQL），東京機房 | 資料庫、登入、檔案、權限規則一包；標準 PostgreSQL，之後好搬家 |
| 網站主機、DNS、防護 | Cloudflare（Workers 付費版，每月 US$5） | 便宜、流量不收費、防 DDoS 與防機器人免費內建 |
| Next.js 部署方式 | OpenNext 轉接到 Cloudflare Workers | Cloudflare 官方支援的做法 |
| 網域 | `sillymomhome.com`（在 Cloudflare 購買） | 跟 repo 名稱一致，DNS 和主機同一個帳號 |
| 視訊通話與錄影 | LiveKit 雲端版 | 開源，可以之後改自架；錄影可以上傳到自己指定的儲存空間 |
| 錄影檔、證件檔存放 | Google Cloud Storage，台灣機房（asia-east1，彰化） | 「錄影和證件存在台灣」可以寫進隱私權政策 |
| 金流與電子發票 | 綠界 ECPay | 台灣常用，金流和電子發票同一家。**開始實作前要先確認：綁卡後能不能由平台直接扣款（不需客戶再操作）**；不行就改用 TapPay |
| 簡訊驗證碼 | EVERY8D | 價格公開、可小量購買 |
| 通知 | LINE 官方帳號（Messaging API）；沒綁 LINE 時改用簡訊 | 台灣使用率最高 |
| LINE 申訴 | 簡單版：官方帳號選單連結到網站「回報與申訴」頁；客服在 LINE 後台手動回覆 | 第一版成本最低 |
| 多語系 | 繁體中文、英文，從第一天就預留 | 之後要中英切換、也可能賣到國外 |

## 2. 第一版用「假模組」的服務

投資人展示版（Milestone 1）不串接真的金流和簡訊，改用「外部服務替換介面」的假模組：

- 金流：按了就顯示成功，不扣款
- 簡訊：驗證碼固定（例如 `123456`），只在開發和展示環境有效
- 通知：只寫進後台紀錄
- 視訊：用 LiveKit 免費版，**是真的視訊**，但先不錄影

正式上線前（Milestone 3）才換成綠界、EVERY8D、LINE 的真模組。

## 3. 收費（後台「平台設定」可以修改）

金額一律從資料庫的平台設定讀取，程式裡不寫死。初始值照設計稿：

**師傅端**
- 上架審核費 NT$300（審核通過才扣，只收一次）
- 平台服務費（視訊）NT$150：視訊滿 3 分鐘才收；新師傅第 1 次視訊免費
- 平台服務費（直接預約到府）NT$150：核對碼確認時收
- 沒拿到這個案子：退 NT$50 抵用金
- 客戶確認問題已在視訊中解決：退 NT$100 抵用金（7 天內同一個問題預約到府就收回）
- 抵用金只能折抵平台費用，不能換現金，3 個月內有效

**客戶端**
- 平台費（求助）NT$100：含 2 次視訊
- 平台費（急件）NT$100、平台費（直接預約到府）NT$100
- 逾時費（臨時取消、沒人開門）NT$100

各項的詳細規則以設計稿的「客戶條款規則」「師傅條款」「平台設定」頁為準。

## 4. 資料保存與個資

| 資料 | 存放 | 保存期限 |
|---|---|---|
| 會員資料、預約、評價等 | Supabase 東京 | 依帳號存續；刪除帳號照「帳號設定」頁的規則處理 |
| 視訊錄影 | Google Cloud 台灣，不公開 | 180 天；超過 30 天自動轉冷儲存（Coldline）；有申訴或在保固期內就延長，結案後再刪 |
| 證件照片（身分證、良民證、證照） | Google Cloud 台灣，不公開、另外加密 | 師傅在職期間保留；停用後再保留約 2 年（**年限請律師確認**）後刪除 |
| 信用卡 | 不經過我們的系統，由綠界保管 | 我們只存綠界給的代號 |

- 證件審核完後，只有「老闆」核准才能調閱，每次調閱都留紀錄（誰、何時、原因）。
- 錄影、證件一律用幾分鐘就失效的短效連結開啟。
- 保存天數做成後台設定。

## 5. 資安

- 資料庫每張表都要有 Row Level Security（每個人只能讀寫自己的資料）
- 後台角色：老闆（全部權限）、審核員（師傅審核）、客服（申訴與會員）
- 管理員登入一律兩步驟驗證；後台所有操作留紀錄
- Cloudflare：DDoS 防護、防火牆規則、Turnstile 防機器人（註冊、登入、送出驗證碼）
- 驗證碼送出限制次數（防灌簡訊）
- 密碼與金鑰只放在環境變數，不進 git
- GitHub Dependabot 檢查套件漏洞
- Supabase Pro 每日備份
- 上線前用 Claude Code 做一輪資安檢查；外部滲透測試之後再請

## 6. 之後的方向（已預留，不在第一版做）

- 賣到歐洲：一個地區一套部署，資料留在當地；改用 Stripe、VAT 發票、Email 通知
- 自架 LiveKit 或 Supabase 在 Google Cloud 台灣機房，讓資料全部留在台灣
- LINE 優先登入、LINE 通知型訊息
- 包成 App：同一個網域
