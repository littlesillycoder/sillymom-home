# 設計補充（2026-11-04 定案）

設計稿裡沒有、實作時才發現要補的設計。對照圖在同一個資料夾。

## 1. 語言切換

**電腦版**（`語言切換_電腦版.png`，看「改成」）
- 頁首右邊：地球圖示 + 文字「English」（切到英文後顯示「中文」）。字 15px、顏色 #4E525C、不加外框。
- 位置：未登入放在「登入」左邊；會員放在通知鈴鐺左邊；師傅放在訊息圖示左邊。
- `aria-label`：「Switch to English」／「切換成中文」。

**手機版**（`語言切換_手機版_其他位置.png` 的「方案 2」）
- 選單最上面，關閉按鈕（X）左邊，地球圖示 + 「EN」（切到英文後顯示「中」）。
- 樣式：高 32、左右內距 10、圓角 999、1.5px #D8D2C4 框、白底、字 13px 粗體。
- 手機頁首不放語言切換；選單最下面也不放（`語言切換_手機版.png` 是舊方案，不採用）。

**自動判斷語言**
- 第一次進網站：依瀏覽器的 `Accept-Language` 選繁中或英文，不是中文就用英文。
- 使用者自己切換過後，記住選擇（cookie），之後以使用者的選擇為準。
- 網址帶語言（`/zh-TW/`、`/en/`）；切換時停在同一頁。

## 2. 頁尾

**電腦版頁尾改成一行**（`頁尾_精簡選項.png` 的「方案 1」，取代設計稿電腦版的三欄頁尾）
- 高約 71：上下內距 22、左右照版面留白，上方 1px #E2DDD2 分隔線，背景同頁面。
- 左邊：「傻媽萬事通」（18px、900 粗）＋「© [年份] 小傻瓜創意國際顧問有限公司」（14px）。公司名稱放在設定裡，之後如果另外成立公司，只改設定。
- 右邊一排連結（15px、#4E525C、間距 20）：服務項目・安全機制與審核標準・成為師傅 ｜ 客服中心・服務條款・隱私政策（中間用淺色直線 #D8D2C4 分組）。
- 拿掉設計稿裡的「水電與漏水、冷氣、家電」（改成「服務項目」）；「安全機制」「審核標準」合成一個連結。
- 螢幕比較窄、一行放不下時，連結換到品牌下一行，靠左。

**手機版公開頁的頁尾**：照設計稿（深色底、三行），不變。

## 4. 寬度 768–1099 的頁首（`頁首_寬度與師傅標籤.png` 第 1 部分）

- 768–1099 一律把頁首的導覽連結收起來，右邊加 ≡ 選單按鈕；點了打開跟手機版一樣的選單（未登入、會員、師傅各自的選單內容）。
- 頁首右邊其他東西保留：語言切換、登入／免費註冊（未登入）、通知、訊息、頭像與名稱（會員、師傅）。
- 1100 以上照設計稿顯示完整導覽列。
- 原因：不收的話，寬 1024 未登入頁首的「成為師傅」會和「English」重疊，寬 800 會員和未登入都會重疊。

## 5. 電腦版師傅頁首加「師傅」標籤（`頁首_寬度與師傅標籤.png` 第 2 部分）

- 品牌名稱「傻媽萬事通」右邊加「師傅」標籤，樣式跟手機版一樣（#3A5A94 底、白字、13px 粗體、圓角 999、左右內距 8）。
- 電腦版設計稿沒有這個標籤，以這裡為準。

## 6. 頁尾的公司名稱

- 目前用「小傻瓜創意國際顧問有限公司」。
- 之後可能另外成立公司經營這個平台；上線前要確認經營公司名稱，並讓頁尾、條款、綠界、LINE 等帳號的公司名稱一致（已列在上線清單）。

## 7. 預約摘要的師傅列：證件用綠色標籤（`預約摘要_證件標籤.png`）

- 確認與付款、預約到府、行程追蹤裡的師傅列，證件（身分驗證、良民證、證照）**一律用綠色打勾標籤**，跟師傅卡的驗證標籤是同一個元件。
- 電腦版設計稿（`desktop/Checkout`）本來就是綠色標籤；手機版設計稿（`mobile/Checkout`）的灰色文字「身分驗證 · 良民證 · 證照」**不採用**，手機版也改成綠色標籤。
