# 設計補充（2026-11-04 定案）

設計稿裡沒有、實作時才發現要補的設計。對照圖在同一個資料夾。

## 1. 語言切換

**電腦版**（`語言切換_電腦版.png`，看「改成」）
- 頁首右邊：地球圖示 + 文字「English」（切到英文後顯示「中文」）。字 15px、顏色 #4E525C、不加外框。
- 位置：未登入放在「登入」左邊；會員放在通知鈴鐺左邊；師傅放在訊息圖示左邊。
- `aria-label`：「Switch to English」／「切換成中文」。

**手機版**（`語言切換_手機版_其他位置.png` 的「方案 2」）
- 選單最上面，關閉按鈕（X）左邊，地球圖示 + 「EN」（切到英文後顯示「中」）。
- 樣式：高 32、左右內距 10、圓角 999、1.5px #D8D2C4 框、白底、字 13px 粗體。
- 手機頁首不放語言切換；選單最下面也不放（`語言切換_手機版.png` 是舊方案，不採用）。

**自動判斷語言**
- 第一次進網站：依瀏覽器的 `Accept-Language` 選繁中或英文，不是中文就用英文。
- 使用者自己切換過後，記住選擇（cookie），之後以使用者的選擇為準。
- 網址帶語言（`/zh-TW/`、`/en/`）；切換時停在同一頁。
