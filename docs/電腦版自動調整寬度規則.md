# 傻媽萬事通：電腦版自動調整寬度規則

給工程（Claude Code）實作用。設計稿的電腦版每頁畫成 1440 寬；正式網站要依下面的規則跟著螢幕寬度調整。手機版另有設計稿（390 寬）。

## 1. 寬度區間

| 區間 | 螢幕寬度 | 用哪一版 |
|---|---|---|
| 大螢幕、一般筆電 | 1100 以上 | 電腦版，左右留白跟著螢幕寬度等比例變 |
| 小筆電、平板橫放 | 768–1099 | 電腦版，欄數變少（見第 3 節） |
| 手機、平板直放 | 767 以下 | 手機版設計稿 |

## 2. 內容寬度與留白

- 左右留白一律是螢幕寬度的 5.56%（= 80 ÷ 1440）：1920 寬各 107px、1440 寬各 80px（和設計稿一樣）、1024 寬各 57px。三種寬度看起來比例一樣。
- 超寬螢幕（2560 以上）內容最寬 2240px，再寬就置中、兩邊留白變大，避免一行字太長。
- 頁首、頁尾、每個區塊（section）的背景色要滿版，只有裡面的內容照上面的留白縮進去。
- 「成為師傅」橫幅這類有圓角的區塊，左右外距也照上面的公式。
- 區塊上下留白：48px；標題和內容的距離：28–32px（設計稿第 5 輪已統一）。

## 3. 欄數

| 元件 | 1100 以上 | 768–1099 |
|---|---|---|
| 首頁「你可以找師傅處理這些事」服務類別 | 4 欄 | 3 欄 |
| 簡易師傅卡（首頁、冷氣頁） | 3 張一排 | 2 張一排，只顯示前 2 位 |
| 安全機制、三個步驟、價格方案 | 3 欄 | 3 欄（夠放）；放不下時改 2 欄 |
| 常見問題 | 2 欄 | 2 欄 |
| 求助頁的問題類別 | 3 欄 | 3 欄 |
| 師傅列表、推薦師傅（詳細卡，一張一排） | 四區橫排 | 狀態移到名字那排右邊，按鈕移到卡片下方靠右 |
| 左主欄＋右側欄的頁面（師傅個人頁、確認與付款、預約到府、公開求助、我信任的師傅、登入後首頁等） | 左右兩欄 | 右側欄移到主欄下面，寬度滿版 |
| 後台（左側選單＋內容） | 左側選單 240 | 左側選單收成只顯示圖示（72） |

建議做法：卡片列用 grid，欄數用上表的兩段（1100 以上、以下）切換；卡片寬度跟著內容寬度伸縮。

## 4. 1099 以下的細部調整

- 首頁首屏：左欄底部的三個勾勾改成直排、不要白框。
- 首頁「安全」卡片：圖示放在標題上面，文字才有足夠寬度。
- 三個步驟的標題可以換行，字級 24 → 22。
- 價格方案的大字 40 → 30，不換行。
- 師傅卡只顯示 2 張，不要出現一排只剩一張。

## 5. 文字

- 首頁首屏大標題：`clamp(36px, 3.5vw, 50px)`，一行放得下「找一位你放心開門的師傅」。
- 其他字級不隨寬度變（16px 內文、20–24px 卡片標題、40px 頁面標題）。
- 換行：
  - `word-break: keep-all; overflow-wrap: break-word;`（詞不從中間斷開，也不會出現「，」開頭的行）
  - 段落 `<p>` 用 `word-break: normal`。
  - 中文和數字、[N] 之間用不換行空白（`&nbsp;`），「·」跟著前面的字。

## 6. 文字連結

- 單獨一行的文字連結靠右；「← 回…」返回連結靠左，放在內容左上角。

## 7. 測試

在 1920、1440、1280、1024、800 這幾個寬度各看一次，確認：
1. 沒有橫向捲軸。
2. 沒有詞從中間斷開，沒有一行只有一個字。
3. 卡片高度在同一排對齊，沒有一排只剩一張孤單的卡（不足就少顯示一張）。
